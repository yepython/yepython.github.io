# Налаштування ЄPython

Цей документ описує, які налаштування є в ЄPython, де вони зберігаються і як відрізняти їх від даних та параметрів запуску.

> Коротко: більшість налаштувань зберігається у `localStorage` браузера під префіксом `OPT_` або у власних ключах (`epython_lang`, `epython_runtime_libs`, `pythonny.lang`). Частина стану живе лише до перезавантаження сторінки, а параметри адресного рядка задають режим запуску, а не постійні налаштування.

## Де зберігаються налаштування

Механізм простий (`lib/lib.js:589-598`):

```js
getOption(name, defaultValue)  // читає localStorage['OPT_' + name]
setOption(name, value)         // пише localStorage['OPT_' + name] = value
```

Наслідки:

- значення зберігаються у **`localStorage`**, тобто прив’язані до походження сторінки (протокол, домен, порт) і переживають перезавантаження та закриття вкладки;
- `sessionStorage` у проєкті **не використовується**;
- значення повертаються як **рядки** (`"12"`, `"dark"`), але CSS/jQuery застосовують їх напряму;
- очищення даних сайту в браузері видаляє й налаштування;
- діалог налаштувань відкривається кнопкою на панелі керування або `Ctrl+O`.

### Повний перелік ключів налаштувань

| Ключ `localStorage` | Діалог | За замовчуванням | Значення | Зберігається |
|---|---|---|---|---|
| `OPT_codeSize` | Налаштування → розмір шрифту коду | `12` | число `6..40` (пт) | так |
| `OPT_outputSize` | Налаштування → розмір шрифту виводу | `12` | число `6..40` (пт) | так |
| `OPT_outputTransparency` | Налаштування → прозорість вікна | `0` | число `0..100` (%) | так |
| `OPT_stepAnimtime` | Налаштування → затримка анімації | `500` | `500..5000`, крок `500` (мс) | пишеться, але **не читається** через помилку в назві |
| `OPT_code_style` | Кольори редактора | `light` | `light`, `dusk`, `dark` | так |
| `OPT_output_style` | Кольори консолі | `dark` | `light`, `dusk`, `dark` | так |
| `epython_lang` | Мова інтерфейсу | мова браузера, інакше `en` | 20 кодів мов | так |
| `epython_runtime_libs` | Середовище виконання → бібліотеки | `{"p5":true,"pandas":true,"sqlite3":true,"processing":true}` | JSON із чотирма булевими полями | так |
| `pythonny.lang` | Tk-вікна (не має UI) | `uk` | `uk`, `en` | так |
| `teacher_theme` | Тільки `teacher_app.html` | `dark` | `light`, `dark` | так |

## Діалог «Налаштування»

Розташований у `index.html:965-1022`, обробники — у `lib/lib.js:2327-2372` та `lib/lib.js:2628-2685`.

### Розміри тексту

| Елемент | Дія | Ключ |
|---|---|---|
| `#slider_code_size` / `#txt_code_size` | змінює `font-size` редактора `#editor`, `6..40 pt` | `OPT_codeSize` |
| `#slider_output_size` / `#txt_output_size` | змінює `font-size` області виводу `#output`, `6..40 pt` | `OPT_outputSize` |
| `#slider_output_transparency` / `#txt_output_transparency` | задає прозорість `#dlg`: `opacity = 1 - value/100`, тобто `0%` — непрозоро, `100%` — повністю прозоро | `OPT_outputTransparency` |

У вбудованій довідці (`help/index.html:839-871`) для тексту рекомендовано розмір `14`.

### Кольори

**Редактор** (`#radio_code_style`) задає одночасно тему CodeMirror, колір тла сторінки й CSS-клас на `body`:

| Радіокнопка | Тема CodeMirror | Тло | Клас | Ключ |
|---|---|---|---|---|
| День | `default` | `#FFF` | `theme-light` | `light` |
| Сутінки | `cobalt` | `#002240` | `theme-dusk` | `dusk` |
| Ніч | `blackboard` | `#000` | `theme-dark` | `dark` |

**Консоль** (`#radio_output_style`) змінює тло й колір тексту `#dlg`:

| Радіокнопка | Тло | Текст | Ключ |
|---|---|---|---|
| День | `#FFF` | `#000` | `light` |
| Сутінки | `#002240` | `#CCC` | `dusk` |
| Ніч | `#222` | `#CCC` | `dark` |

CSS-змінні для тем оголошені безпосередньо в `index.html:113-153` (`:root`, `body.theme-dark`, `body.theme-dusk`).

### Режим запуску

Радіогрупа `#radio_run_mode` (`lib/lib.js:2628-2643`) встановлює `PythonIDE.runMode`:

| Радіокнопка | Значення | Що робить |
|---|---|---|
| Уся програма | `normal` | звичайний запуск, іконка `play.png` |
| Покроково | `step` | покрокове виконання, іконка `step.png`; також `Shift+F5` |
| Анімація рядків | `anim` | послідовне виконання з затримкою |

Затримка для режиму анімації задається повзунком `#slider_step_anim_time` (`500..5000 мс`); фактичне значення береться безпосередньо з елемента (`lib/lib.js:1798-1803`).

> **Увага:** цей режим **не зберігається** — після перезавантаження сторінки знову буде `normal`.

## Діалог «Середовище виконання»

Відкривається кнопкою з шестернею всередині вікна «Налаштування» (`#btn_open_runtime`, `index.html:1016-1020`; обробник `lib/addfuncs.js:110-136`).

У вікні (`index.html:1025-1054`) показано:

- версію Skulpt (`1.3.0`) і Python (`3.7+`) — це довідкові відомості, не налаштування;
- кнопку вибору мови `#epylang_btn`, яку динамічно додає `lib/main.js:16-26`;
- таблицю підтримуваних бібліотек `#rt_libs_tbody`.

### Бібліотеки

Усі бібліотеки зі списку `RT_LIBS` (`lib/addfuncs.js:4-25`) показані в таблиці, але **змінювати можна лише чотири**:

| Бібліотека | Можна вимкнути |
|---|---|
| `p5` | так |
| `pandas` | так |
| `processing` | так |
| `sqlite3` | так |
| `arduino`, `easygui`, `matplotlib`, `microbit`, `music`, `numpy`, `pygame`, `pgzrun`, `robot`, `SimpleGraphics`, `soundfx`, `tkinter`, `turtle`, `withcode`, `os`, `PIL` | ні (чекбокс увімкнено й заблоковано) |

Стан зберігається у `epython_runtime_libs` як JSON-об’єкт (`lib/addfuncs.js:27,44-56,90-96`). Типові значення — усі чотири прапорці `true`.

> Зміни набувають чинності **після перезавантаження сторінки**, бо відповідні скрипти підключаються у `index.html:513-531` під час завантаження.

## Мова інтерфейсу

Мову можна змінити кнопкою з прапорцем у діалозі «Середовище виконання» або через параметр `?lang=...` в адресі (див. також [README-VFS.md](README-VFS.md), розділ про параметри запуску).

**Пріоритет вибору** (`lib/langloader.js:90-99`):

1. `?lang=...` з URL;
2. збережене значення `localStorage.epython_lang`;
3. мова браузера з `navigator.languages`, якщо вона підтримується;
4. англійська (`en`).

Підтримувані коди (`lib/langloader.js:50-61`):

```text
uk pl cs sk bg sr hr en de nl sv da no fr es it pt ro lt lv
```

Нормалізація: регістр не враховується, `uk-UA`/`uk_UA` стає `uk`, `nb`/`nn` стає `no`.

Особливості:

- перший запуск без `?lang` і без збереженого значення показує вікно вибору мови (`lib/main.js:71-75`);
- вибір мови зберігає знімок коду, ставить `loadAction='restoreCode'` і перезавантажує сторінку (`lib/langloader.js:142-159`), щоб код не загубився;
- шлях до мовних файлів можна змінити через `window.EPYTHON_LANG_DIR` до підключення `langloader.js` (`index.html` та `lib/main.js` за замовчуванням використовують `lib/lang/`);
- англійська завантажується завжди як запасний варіант для відсутніх ключів (`lib/langloader.js:108-109`);
- сторінка вчителя `teacher_app.html:706-722` читає той самий ключ `epython_lang` (і застарілий fallback `teacher_lang`, який ніде не записується).

> У коментарі `lib/langloader.js:13` досі написано, що `?lang` діє «лише на цей сеанс, без запису». Це не відповідає коду: рядки `:95-99` **справді зберігають** значення в `localStorage`.

## Стан поточної сесії

Наступні перемикачі **не зберігаються** у `localStorage` і скидаються після перезавантаження:

| Стан | Де задається |
|---|---|
| Режим запуску `normal`/`step`/`anim` | `#radio_run_mode`, `lib/lib.js:2628-2643` |
| Видимість панелі інструментів | `#btn_tools`, `lib/lib.js:2794-2800` |
| Відкриття/закриття консолі `#dlg` | `#btn_show_output`, `lib/lib.js:2802-2810` |
| Бічна панель файлів проєкту | `#btn_toggle_file_sidebar`, `lib/lib.js:2067-2084` |
| Мобільне розгортання нижньої панелі | інлайн-скрипт `index.html:1160-1188` |
| Режим іспиту | тільки `?mode=exam`, `index.html:681-725` |
| Режим робота, швидкість/скін/сітка/згорнута карта | `index.html:662-679`, `lib/skulpt/robot/robot-ui.js` (швидкість за замовчуванням `5`) |
| Поточний файл і назва проєкту | `PythonIDE.currentFile = 'mycode.py'`, `index.html:799-805` |

Параметри адресного рядка (`mode`, `load`, `run`, `code`, `runcode`, `paste`, `assets`, `task`, `world`) належать до **запуску**, а не до постійних налаштувань. Виняток — `lang`: він змінює постійну мову. Повний перелік — у [README-VFS.md](README-VFS.md).

## Tk-вікна

Tk-рушій має власну локалізацію, окрему від IDE:

| Аспект | Факт |
|---|---|
| Ключ | `pythonny.lang`, за замовчуванням `uk` (`lib/tk/tk-window-system.js:367-381`) |
| Пріоритет | `?lang` → збережене значення → `uk`; `?lang` враховується, лише якщо код є в `MESSAGES` |
| Мови | фактично лише `en` і `uk`, запасний варіант — `en` (`lib/tk/tk-window-system.js:25-101,392-399`) |
| `setLanguage()` | змінює лише змінну в пам’яті, **не пише** в `localStorage` (`:387-390`) |
| Теми | доступні `winnative`, `clam`, `alt`, `default`, `classic`, `vista`, `xpnative`; поточна — `vista` (`lib/tk/tk-engine.js:7442-7475`) |
| UI | окремого діалогу теми/шрифтів Tk немає; кольори й шрифти не зберігаються |

Практично: `?lang=en` впливає і на IDE, і на Tk під час завантаження, але пізніша зміна мови через `setLanguage()` не.sync з `epython_lang`.

## Ключі, які не є налаштуваннями

Ці ключі теж лежать у `localStorage`, але є **даними або службовим станом**:

| Ключ | Призначення |
|---|---|
| `epythonfs_filesystem`, `epythonfs_file_N` | віртуальна файлова система (див. [README-VFS.md](README-VFS.md)) |
| `vault` | знімки коду для «Відновлення файлу» |
| `aT` | внутрішній стан застосунку (JSON) |
| `loadAction` | одноразова команда після перезавантаження (`showShare`, `restoreCode`); видаляється після виконання |
| `replHistory` | історія консолі |
| `sqlite_<filename>` | вміст баз даних SQLite |
| `yepython_test_task` | завдання для пробного запуску з `teacher_app.html` (`?mode=exam&task=test`) |
| `<file.name>` | завантажені графічні ресурси у вигляді Data URL |
| `lookupLocalStorage`, `<key>p5TypeID` тощо | внутрішнє сховище бібліотек p5/Processing/pandas |

Окремо:

- `localStorage.options` (`lib/lib.js:2319-2326`) створюється «на всяк випадок», але **жоден `getOption()` його не читає** — застарілий запис без впливу;
- `localStorage.debug` (`lib/lib.js:2712-2724`) передбачав прапорець «додаткові можливості», але елемента `#chk-advanced` у HTML немає, тож через UI його ввімкнути неможливо.

## Відомі особливості та вади

1. **Помилка в назві ключа затримки анімації.** Слайдер пише `OPT_stepAnimtime` (`lib/lib.js:2369`), а читає `OPT_stepAnimTime` (`lib/lib.js:2363`, `:2372`). Після перезавантаження повзунок знову покаже `500 мс`.
2. **Застарілий `localStorage.options`.** Створюється, але не використовується.
3. **Недосяжний `localStorage.debug`.** Немає відповідного прапорця `#chk-advanced` у розмітці.
4. **Коментар про `?lang` застарів.** Насправді параметр зберігається в `epython_lang`.
5. **`teacher_lang` читається, але ніколи не пишеться** (`teacher_app.html:713`).
6. **Tk-мова не синхронізується** з `epython_lang` після виклику `setLanguage()`.
7. **Режим запуску й видимість панелей не зберігаються** — це стан сеансу.
8. **Зміни бібліотек потребують перезавантаження** сторінки.
9. **Усі `OPT_*` значення — рядки.** Чисельні значення застосовуються в CSS як `ui.value + "pt"` / `+ "%"`.
