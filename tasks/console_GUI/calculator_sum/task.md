# Завдання: Калькулятор (режим Tkinter + консоль)

## Умова
Введіть два числа в консолі (кожне з нового рядка) та відобразіть результат їх додавання у графічному вікні Tkinter у вигляді напису (Label).

## Режим перевірки
`both` — перевіряється консольний вивід (якщо є `input()`) та графічний інтерфейс Tkinter.
