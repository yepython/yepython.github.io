# Завдання: Перевірка пароля (режим Tkinter + консоль)

## Умова
Введіть пароль у консолі. Правильний пароль — «python123». У графічному вікні Tkinter відобразіть напис (Label): «Доступ дозволено», якщо пароль правильний, або «Доступ заборонено», якщо ні.

## Режим перевірки
`both` — перевіряється консольний вивід (якщо є `input()`) та графічний інтерфейс Tkinter.
