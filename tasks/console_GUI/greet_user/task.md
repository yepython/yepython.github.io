# Завдання: Привітання користувача (режим Tkinter + консоль)

## Умова
Введіть ім'я в консолі (input) та відобразіть вітання у графічному вікні Tkinter у вигляді напису (Label): «Привіт, <ім'я>!».

## Режим перевірки
`both` — перевіряється консольний вивід (якщо є `input()`) та графічний інтерфейс Tkinter.
