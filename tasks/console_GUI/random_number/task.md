# Завдання: Генератор випадкових чисел (режим Tkinter + консоль)

## Умова
Введіть у консолі межі діапазону: мінімальне та максимальне значення (кожне з нового рядка). У вікні Tkinter створіть кнопку «Згенерувати» та напис (Label). Початково напис порожній. Після натискання кнопки в написі має з'явитися випадкове ціле число в заданому діапазоні.

## Режим перевірки
`both` — перевіряється консольний вивід (якщо є `input()`) та графічний інтерфейс Tkinter.
