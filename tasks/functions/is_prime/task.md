# Завдання: Перевірка простого числа (режим функцій)

## Умова
Створіть функцію `is_prime(n)`, яка повертає `True`, якщо число `n` є простим, інакше `False`. Числа менші за 2 не є простими.

## Приклад
- `is_prime(7)` → `True`
- `is_prime(8)` → `False`

## Режим перевірки
`functions` — викликаються функції з тестовими аргументами, порівнюється результат.
