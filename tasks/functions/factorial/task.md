# Завдання: Факторіал (режим функцій)

## Умова
Створіть функцію `factorial(n)`, яка обчислює факторіал числа `n` (n ≥ 0). Факторіал 0 дорівнює 1.

## Приклад
- `factorial(5)` → `120`
- `factorial(0)` → `1`

## Режим перевірки
`functions` — викликаються функції з тестовими аргументами, порівнюється результат.
