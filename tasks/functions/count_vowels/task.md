# Завдання: Кількість голосних (режим функцій)

## Умова
Створіть функцію `count_vowels(s)`, яка повертає кількість голосних латинських літер (`a`, `e`, `i`, `o`, `u`) у рядку без урахування регістру.

## Приклад
- `count_vowels('hello')` → `2`
- `count_vowels('AEIOU')` → `5`

## Режим перевірки
`functions` — викликаються функції з тестовими аргументами, порівнюється результат.
