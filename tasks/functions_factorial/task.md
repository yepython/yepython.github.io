# Завдання: Факторіал (режим функцій)

## Умова
Напишіть функцію `factorial(n)`, яка повертає факторіал числа `n` (n ≥ 0).
Факторіал 0 = 1.

## Приклад
- `factorial(5)` → `120`
- `factorial(0)` → `1`

## Режим перевірки
`functions` — викликаються функції з тестовими аргументами, порівнюється результат.
