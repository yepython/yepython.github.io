# Завдання: Сортування без використання sort() (режим консолі)

## Умова
Прочитайте рядок із цілих чисел, розділених пробілами, і виведіть їх за зростанням через пробіл. Використовувати sort() і sorted() заборонено.

## Приклад
Вхід:
```
3 1 2
```
Вихід:
```
1 2 3
```

## Режим перевірки
`console` — порівнюється стандартний вивід програми на наборі тестів.
