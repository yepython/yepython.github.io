# Завдання: Перевірка простого числа (режим консолі)

## Умова
Прочитайте ціле число n і виведіть «просте», якщо воно просте, або «не просте» в іншому разі. Простим є число, яке має рівно два дільники (1 і саме себе).

## Приклад
Вхід:
```
2
```
Вихід:
```
просте
```

## Режим перевірки
`console` — порівнюється стандартний вивід програми на наборі тестів.
