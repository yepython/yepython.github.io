# Завдання: Паліндром (режим консолі)

## Умова
Прочитайте рядок без пробілів і виведіть «паліндром», якщо він читається однаково в обидва боки, або «не паліндром» в іншому разі.

## Приклад
Вхід:
```
level
```
Вихід:
```
паліндром
```

## Режим перевірки
`console` — порівнюється стандартний вивід програми на наборі тестів.
