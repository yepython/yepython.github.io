# Завдання: Числа Фібоначчі (режим консолі)

## Умова
Прочитайте число N і виведіть перші N чисел Фібоначчі через пробіл. Послідовність починається з 0, 1 (F0 = 0, F1 = 1).

## Приклад
Вхід:
```
1
```
Вихід:
```
0
```

## Режим перевірки
`console` — порівнюється стандартний вивід програми на наборі тестів.
