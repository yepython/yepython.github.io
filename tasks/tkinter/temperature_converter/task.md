# Завдання: Конвертер температури (режим GUI)

## Умова
Створіть поле введення (Entry) для температури в градусах Цельсія, кнопку «Конвертувати» та напис (Label) для результату. При натисканні кнопки в написі має з'явитися температура у градусах Фаренгейта за формулою F = C * 9/5 + 32.

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
