# Завдання: Повзунок (режим GUI)

## Умова
Створіть повзунок (Scale) від 0 до 100 з початковим значенням 0 (горизонтальний) та напис (Label), що показує поточне значення повзунка. При зміні положення повзунка напис має оновлюватися.

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
