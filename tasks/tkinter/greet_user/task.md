# Завдання: Привітання користувача (режим GUI)

## Умова
Створіть поле введення (Entry), кнопку з текстом «Привітати» та напис (Label). Після натискання кнопки напис має показати: Привіт, <ім'я>!, де <ім'я> — текст із поля введення.

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
