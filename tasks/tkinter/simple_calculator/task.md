# Завдання: Простий калькулятор (режим GUI)

## Умова
Створіть два поля введення (Entry), кнопки «+» і «-» та напис (Label) для результату. При натисканні «+» у написі має з'явитися сума чисел з полів, при натисканні «-» — різниця (перше мінус друге).

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
