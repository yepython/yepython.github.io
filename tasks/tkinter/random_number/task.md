# Завдання: Генератор випадкових чисел (режим GUI)

## Умова
Створіть кнопку з текстом «Згенерувати» та напис (Label). Початково напис порожній. При натисканні кнопки в написі має з'явитися випадкове ціле число від 1 до 100 (використовуйте модуль random).

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
