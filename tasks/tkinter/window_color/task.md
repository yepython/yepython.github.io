# Завдання: Зміна кольору вікна (режим GUI)

## Умова
Створіть три кнопки: «Червоний», «Зелений», «Синій». При натисканні кнопки колір фону головного вікна має змінитися на відповідний (red, green, blue).

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
