# Завдання: Список фруктів (режим GUI)

## Умова
Створіть список (Listbox) з елементами «Яблуко», «Банан», «Апельсин» та напис (Label). При виборі елемента списку в написі має з'явитися назва вибраного фрукта. Початково напис порожній.

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
