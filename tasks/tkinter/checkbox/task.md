# Завдання: Прапорець (режим GUI)

## Умова
Створіть прапорець (Checkbutton) з текстом «Погоджуюсь», кнопку «Перевірити» та напис (Label). Початково напис показує «Ні». Після натискання «Перевірити»: якщо прапорець увімкнено — напис показує «Так», інакше — «Ні».

## Режим перевірки
`gui` — запускається програма, виконуються дії (натискання, введення тощо), порівнюються знімки інтерфейсу.
